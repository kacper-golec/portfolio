Moje prywatne projekty:
1. Pogoda - Program jest zbudowany na bazie biblioteki customtkinter oraz API ze strony openweathermap.
   Po wpisaniu miasta program pokaze nam temperature, pogode, wilgotnosc w danym mieście jak i prognoza na następne 5 dni. W aplikacji możemy wpisywać
   dowolne miasta z całego świata.
2. Kalkulator - Program jest zbudowany na bazie biblioteki tkinter jako mój pierwszy projekt oraz przyswajania wiedzy z dokumentacji biblioteki.
   Można w nim wykonywać proste obliczenia.
